# redes-resumen-osi
Resumen hecho a modo de repaso sobre el modelo OSI y algunos protocolos

# Descripción

Este repositorio contiene un resumen personal de estudio sobre infraestructura y redes informáticas, elaborado como parte de mi formación continua en IT y ciberseguridad.

# Contenidos

Modelos OSI y TCP/IP.

Protocolos de red: TCP, UDP, DNS, DHCP, HTTP/HTTPS y SSH.

Direccionamiento IPv4 e IPv6 y subnetting.

ARP, enrutamiento y NAT.

Ethernet, VLAN y redes Wi-Fi.

Capa física y medios de transmisión.

Objetivo

Organizar y consolidar los conocimientos adquiridos, comprender cómo interactúan las distintas capas de red y construir una base técnica para continuar desarrollándome en el área de IT y ciberseguridad.

Nota: Este material es un resumen personal de aprendizaje y puede actualizarse a medida que incorpore nuevos conocimientos.
